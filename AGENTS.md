# Repository delivery workflow

- Deliver each completed feature or improvement as its own reviewable work unit.
- Include its implementation, tests, and relevant documentation/assets in the same commit.
- Run the relevant checks before committing; use Conventional Commit messages.
- Push each completed feature commit to its configured upstream immediately after committing, unless the user explicitly asks to hold or avoid a push.
- Do not combine unrelated completed features in one commit or add AI attribution.
